Shorts Engine

A self-hosted tool for making and uploading YouTube Shorts.

Shorts Engine runs on its owner's own computer. It ranks trending Shorts, writes faceless scripts, renders videos with stock footage, captions and music, and uploads them to the owner's YouTube channel. It reads the channel's own video statistics so that the videos that perform well on the channel get made more often.

The source code is public: github.com/bigmo6286/youtube-shorts-automation.
