Or clone a channel's style

      
Paste a channel URL or @handle. The tool reads its most-viewed Shorts, classifies them, and has Claude distil a style guide (voice, hooks, structure, pacing). Videos produced from a profile use that style with new subjects.

      

        
        
        
      

      

        
        
        
        
        
      

      

    

    

      
Or use your own script

      
By default your script is enhanced: Claude adds a scroll-stopping hook, tightens the flow for a fast voiceover and makes sure the ending pays off, keeping every fact and your point. TypeSafe checks the hook, clarity, payoff, policy risk and that nothing was changed or invented, and sends weak drafts back for another pass. Tick "as written" to voice your text exactly as it is.

Channel performance feedback

        
With a YouTube Data API key and your channel handle (both above), the tool reads your uploads' public view counts, matches them to the Shorts it produced (by title, so keep the generated titles when uploading), and gives blueprints that perform well on your channel a bigger share of production. Synced with every trend refresh.

        

        
How to get a YouTube Data API key (read-only, no OAuth)
          
  1. console.cloud.google.com → your project → APIs & Services → Enable YouTube Data API v3
    2. 
          
  2. Credentials → Create credentials → API key → copy it into the YouTube Data API key field
    3. 
          
  3. Put your channel handle (e.g. @yourname) in the channel field, save, then Sync.

Automatic uploads

          
Scheduled Shorts wait in an upload queue. TypeSafe predicts each one's priority (scroll-stopping hook, fit with what works on your channel, watch-through) and the best ones are uploaded automatically, within the daily limit, spaced out. The limit lowers itself if YouTube refuses an upload.
